# MetalTrack — Jewellery Retail Analytics

## Project Overview
MetalTrack is a business intelligence project developed using a fictional jewellery retail dataset. It analyses metal rates, inventory, stock movements, purchasing, wholesale sales, and making charges to support data-driven business decisions.

## Tools and Technologies
- PostgreSQL — Database management
- SQL — Data preparation and business analysis
- Microsoft Excel — Analytical reports and charts
- Power BI and DAX — Interactive dashboards and KPIs
- Microsoft Word and PowerPoint — Project documentation and presentation

## Project Deliverables
- 24 PostgreSQL source tables
- 17 analytical SQL views
- 15 SQL business analyses
- 4 Excel analytical reports
- 6 Power BI dashboard pages
- 50 DAX measures
- Data dictionary covering 544 fields
- Final project report and presentation

## Key Business Findings
- Gold rate change: 15.46% across the analysed period
- Top five branches: 58.37% of closing stock weight
- January 2026 purchasing: 235.93% increase versus December 2025
- Top ten wholesale customers: 88.63% of analysed wholesale sales
- Metal products: 66.14% of analysed wholesale sales
- Making charges: approximately 3.86% of analysed net sales

## Repository Structure
- `SQL_Scripts/` — SQL scripts and analytical queries
- `Excel_Reports/` — Excel analytical reports
- `PowerBI/` — Power BI dashboard file
- `Data_Dictionary/` — Database field documentation
- `Documentation/` — Final report and presentation

## Business Recommendations
- Review branch-level inventory concentration
- Improve purchasing planning and monitoring
- Reduce wholesale customer concentration risk
- Monitor metal-rate changes and pricing
- Investigate unusual stock movements
- Review making-charge consistency

## Project Limitations
This project uses fictional data. Reporting periods vary across analyses, and currency and weight units have not been independently confirmed. Inventory reconciliation does not establish physical stock accuracy. Making-charge percentages should not be interpreted as profit margins.

## Future Improvements
- Automated data refresh
- Forecasting and predictive analytics
- Enhanced data quality controls
- Expanded KPI monitoring and alerts

## Conclusion
MetalTrack demonstrates an end-to-end analytics workflow, transforming transactional jewellery retail data into SQL analyses, Excel reports, and interactive Power BI dashboards.
